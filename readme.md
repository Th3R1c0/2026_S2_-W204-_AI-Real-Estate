# AI Real Estate (Haven)

An AI-powered real estate discovery platform built for the 2026 S2 W204 project.

The application leverages **Google Gemini 3.5 Flash-Lite** and **Next.js 16** to offer natural-language property search, specialist architectural/hazard filtering, automated comparable sales analysis, side-by-side home comparisons, and live mortgage calculations.

## 🚀 Getting Started

To run the application locally:

```bash
cd ai-real-estate
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the application.

For environment setup (such as configuring `GEMINI_API_KEY` in `.env.local`), testing with Vitest, and architecture details, refer to the [Application README](ai-real-estate/README.md).
