Collection method

One-time snapshot: select candidates from the 2020 Auckland research dataset, verify each full address and coordinate against current LINZ records, request six PropValues URL lookups per address, then request available value endpoints only after an address match. QV numeric links were checked against their public page titles. Its PropertyValue mid value is calculated from the low and high values. PropValues response diagnostics identified Cheerio for HTML sources and a JSON platform API for RealEstate. Trade Me links remained opaque and were not assigned a value. No automatic refresh is configured.
